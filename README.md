# Minimap Code Overview

Continuous code overview panel with viewport slider and interactive dragging

## Details
- **Identifier**: `matn.ext.minimap`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Minimap Code Overview**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-minimap
```
